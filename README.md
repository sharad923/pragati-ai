# Pragati AI

### Team: Syntax Squad

Pragati AI is an AI-powered Rural Development Decision Support Platform designed to help government officials make data-driven decisions for rural development.

## Problem Statement

Government officials often struggle to prioritize villages for development because information such as public complaints, infrastructure status, ongoing projects, and resource availability is scattered across multiple sources.

## Our Solution

Pragati AI analyzes village data and citizen complaints to identify high-priority villages and recommend where resources and budgets should be allocated for maximum impact.

## Key Features

* AI Complaint Analysis
* Village Priority Ranking
* Budget Recommendation
* Interactive Dashboard
* Complaint Management
* Project Tracking
* Explainable AI Recommendations
