# Pragati AI

Pragati AI is an AI-powered Rural Development Decision Support Platform that helps government officials prioritize villages for development using complaint analysis, infrastructure indicators, and AI recommendations.

## Features

- Complaint Analysis
- Village Priority Ranking
- AI Recommendation
- Budget Allocation
- Dashboard
- Maps
- Project Tracking

## Tech Stack

- React
- Spring Boot
- PostgreSQL
- OpenAI API
- Tailwind CSS
